# Frontend Engineer Hiring Plan

## Timeline
- **May 5–16 (Week 1–2)**: Sourcing and outreach
- **May 19–30 (Week 2–3)**: Screening and technical interviews
- **June 2–6 (Week 4)**: Final interview and offer
- **June 9–20 (Week 5–6)**: Onboarding and start

## Sourcing Strategy

### Primary channels (week 1)
1. **LinkedIn**: Search React engineers in key geographies, personalized outreach
   - Target: 3+ years, recent projects involving animations/interactions
   - Message: brief, mission-focused, link to job description
   
2. **AngelList**: Post job, browse early-stage startup engineers
   - High intent (they're looking for startup roles)
   - Target: 50+ applications in week 1
   
3. **GitHub**: Search React contributors by commit history
   - Look for: active projects, component libraries, animation work
   - Outreach: personalized messages on repos or email
   
4. **Referrals**: Reach out to network (advisors, investor intros, team connections)
   - High signal: referred candidates often have lower bar but higher conversion

### Secondary channels (week 2 if needed)
- Indie Hackers, Dev.to communities
- Reddit (r/reactjs, r/learnprogramming)
- Tech newsletters (JavaScript Weekly, React Digest)
- Recruiting agencies (if volume is low)

## Target profile
- 3+ years React or Vue production experience
- Evidence of animation/interaction work (portfolio, GitHub, case study)
- Shipped 1+ features end-to-end
- Clear communication; can explain tradeoffs

## Interview Process

### Round 1: Screening call (30 min)
- **Goal**: assess communication, ownership mindset, animation experience
- **Questions**: 
  - Tell me about a project where you owned the UI/frontend
  - What animation or interaction library have you used? Why did you pick it?
  - What's your approach to state management? (Design patterns, not frameworks)
- **Pass criteria**: enthusiastic about startup, shows ownership, has animation experience

### Round 2: Technical interview (90 min)
- **Goal**: assess design thinking, React depth, real-time problem-solving
- **Live design exercise**: given a design file or user story, design a component or state pattern
  - e.g., "Design a form with validation, async submission, and error recovery"
  - or "Design the state architecture for a dashboard with filters and animations"
- **Pass criteria**: clear thinking, can justify decisions, asks good questions

### Round 3: Take-home project (2–3 hours async)
- **Goal**: assess code quality, shipping ability, animation chops
- **Task**: build a small interactive component from a design file
  - e.g., "Build a toggle button with a smooth animation" or "Implement a collapsible list with Framer Motion"
  - Should include: JSX structure, styling, animation, tests, README
- **Evaluation**: code cleanliness, animation smoothness, attention to detail, README quality
- **Pass criteria**: production-ready code, smooth animation, shipped with tests

### Round 4: Final interview with CEO (30–45 min)
- **Goal**: mission fit, team dynamics, cultural alignment
- **Topics**: why startups, career goals, how they learn, questions for CEO
- **Pass criteria**: excited about the mission, asks thoughtful questions

## Metrics (target)
- **Sourcing**: 50+ inbound applications + 20 outbound outreach = 70 candidates by end of week 2
- **Screening**: 70 → 10 qualified candidates (14% pass rate)
- **Technical + take-home**: 10 → 3 finalists (30% pass rate)
- **Final interview**: 3 → 1 offer (33% pass rate)
- **Offer acceptance**: 1/1 (100% if we don't rush)

## Contingency
- If no qualified offer by June 1: extend final interview to week 5, start onboarding in parallel
- If offer rejected: move to runner-up finalist immediately

## Success criteria
- Offer accepted by June 4
- Start date: June 9 or June 16
- Onboarding plan in place (repo access, design files, pairing schedule)
